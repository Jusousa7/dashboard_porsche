# dashboard_porsche
Dashboard criada com intuito exclusivo de estudos para o curso da DIO.

Olá, esta é uma dashboard criada com o chat gpt sobre vendas da porsche. A base de dados veio do curso de Excel e Ia com Claude e nesta dashboard foram respondidas as seguintes perguntas: Quais os principais modelos de carro vendidos por cidade; Qual o ano de modelo de carro que mais saiu em um periodo; Quero um insight de carros populares de vendas com base nos dados em cada cidade (posteriormente pedi para alterar de cidade para estado e pedi para incluir um gráfico analisando a receita gerada em cada estado).
O Desing foi gerado nas cores vermelho, preto e branco com um estilo elegante e tecnológico.
